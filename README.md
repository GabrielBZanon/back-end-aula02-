# back-end-aula02-
## Sistema de Gerenciamento de Tarefas

Exemplo de CRUD simples full-stack com uma tabela de Tarefas.
![image](https://github.com/user-attachments/assets/098f1f68-ff95-479d-91e4-5b3a3cbf4d8b)
# Tecnologias
- Frontend: HTML, CSS e JavaScript
- Backend: NodeJS com Express
- Banco de Dados: MySQL
# Requisitos
- Git
- NodeJS
- MySQL
- VsCode
# Como rodar
- Clonar o repositório
- Abrir o projeto no VsCode
- Abrir o terminal cmd ou bash, navegar até a pasta ./api e rodar:
-- cd api
-- npm install
-- npm start
ou
npx nodemon
Instalar o Banco de dados no Mysql (Via XAMPP dar start em MySQL).
Navegar até a pasta ./web e executar o arquivo index.html no navegador ou via live server do VsCode
